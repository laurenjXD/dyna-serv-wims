# Dyna-Serv WIMS User Manual Library

The canonical operational manual is [`../USER_MANUAL.md`](../USER_MANUAL.md). The files in this folder are detailed companion chapters, not independent policy documents.

## Reading order

1. Start with the unified manual for access, navigation, role boundaries, mobile/desktop behavior, and end-to-end tutorials.
2. Open the relevant companion chapter for the detailed SOP or exception procedure.
3. When a procedure conflicts with the application, stop the transaction, record the route/record/error, and escalate; do not rely on an old copy.

**Reconciliation rule:** update the unified manual and the affected companion chapter in the same documentation change. Each companion chapter records its last reconciliation date in its header.
